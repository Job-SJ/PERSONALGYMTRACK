# Design system

Use deep charcoal for the canvas, quiet gray-blue borders and lime to signal actions and active states. Keep body copy and secondary metrics clearly differentiated. Dense metric rows use tabular numbers and avoid decorative illustrations. Dark, OLED and light themes share semantic tokens in app/style.css.

The dashboard combines a wide performance plot and a narrower front/back anatomical schematic. The map is a broad-region illustration. Its fill indicates relative direct working-set counts in the selected range. The body page balances a trend against a short entry form. The recap uses a larger typographic treatment.

The desktop sidebar collapses. The mobile layout uses bottom navigation and a command palette. Dialog search is keyboard-accessible. Charts expose table alternatives, forms use native labels, and transitions respect the OS reduced-motion preference.
